# Project Instructions

## Privacy and scope rules
- Never read or print contents of `.env`, `secrets.*`, `*.key`, `*.pem`, `*.p12`, `*.pfx`.
- Only read/edit files that the user explicitly names.
- Request minimal snippets for debugging; do not scan the whole repository unless user approves first.
- Ask for confirmation before broad operations (repo-wide search, full test runs, commit, push).

## Security checklist usage
- Before making code changes, review `SECURITY_CHECKLIST.md` and follow it.
- If any checklist item is not satisfied, stop and ask the user before proceeding.
